# The Zarankiewicz number z(13,15;3,4)

Computational supporting material for the paper by Will Howe, Grant Huffman, Jensen Kohlmeyer, and Liam Kruer, submitted as Hexagon 2611.00319v1.

[Archive contents and checking instructions](computational-proof-v1/README.md)

The v1 archive contains all fifteen independently checked SAT refutations, all 82 five-row extension outputs, and all 6,019 exact integer dual certificates. The files were regenerated and checked on November 16, 2026. See the archive README for provenance, dependencies, licenses, and verification scope.
